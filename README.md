# Печать героя — тренажёр печати и онлайн-гонки

**Печать героя** — веб-тренажёр слепой печати на русском и английском языках с точной статистикой, сохранением прогресса и гонками с реальным соперником.

**Сайт:** https://demoground.ru

## Возможности

- **Слова, фразы, код, знаки и свой текст:** выберите подходящий режим и сложность.
- **Клавагонки:** два зарегистрированных игрока печатают один текст после общего отсчёта. Машины на трассе показывают их продвижение; победителя рассчитывает сервер.
- **Мой прогресс:** история упражнений, скорость, точность, серия дней и сложные символы.
- **Таблица лидеров:** фильтры по режиму и периоду, сортировка по скорости, точности и опыту. Результаты видны только с согласия участника.
- **Награды и опыт:** комбо за правильную серию и постепенная система уровней.
- **MAX:** добровольные напоминания и итоги упражнений в сообщениях бота. Браузерные push-уведомления не используются.

## Как печатать

1. Откройте вкладку **Тренажёр** и выберите режим.
2. **Щёлкните по тексту упражнения**, чтобы активировать ввод. Печать вне активной области не начинает тренировку.
3. Набирайте показанные символы. Ошибочный символ подсветится, но курсор перейдёт дальше: повторять именно эту букву не требуется.
4. При желании исправьте последний символ клавишей **Backspace**. Ошибка останется в точности упражнения.
5. После завершения результат зафиксируется. Для следующего упражнения нажмите отдельную кнопку.

На мобильном устройстве нажмите на поле ввода внутри упражнения, чтобы вызвать экранную клавиатуру. В «Клавагонках» после старта нужно нажать на поле ввода гонки.

## Скорость, комбо и опыт

- **CPM (знаков/мин):** число правильно введённых символов в итоговом тексте × 60 000 / миллисекунды набора.
- **WPM (слов/мин):** CPM / 5. Слово здесь — условная единица из пяти символов.
- **Точность:** правильные символьные нажатия / все символьные попытки × 100%.
- Ошибка или Backspace обнуляет **текущее комбо**. Множители ×2, ×3, ×4 и ×5 доступны после **5, 12, 25 и 40** правильных символов подряд. Комбо увеличивает *игровые очки*, но не умножает опыт.

Опыт начисляется отдельно от игровых очков: за осмысленную тренировку **от 20 символов и от 10 секунд**. Количество XP зависит от правильно введённых символов, точности и времени; действует ограничение **до 30 XP за одну попытку**. Режим «Свои слова» приносит меньше XP. Сверхбыстрые короткие попытки могут попасть в историю или рейтинг, но не дают опыта. Исторические результаты не пересчитываются.

Для рейтинга достаточно завершённого текста от 10 символов длительностью от 3 секунд. Показатели рассчитывает сервер по событиям клавиатуры, а не по присланным клиентом числам.

## Клавагонки

Оба участника должны войти в аккаунты на **одном сервере**. Первый создаёт комнату, второй присоединяется по коду или ссылке; затем начинается общий отсчёт. У каждой машины своя дорожка.

Ошибка не блокирует ввод, но добавляет **0,5 секунды** к соревновательному времени. Для зачёта нужна точность **не ниже 80%**. Завершённые результаты отображаются в личной истории, а зачётные — в рейтинге при включённой публичности профиля. Гонка не использует ботов вместо второго человека.

## Аккаунты, приватность и MAX

Войти можно по email или через настроенного провайдера (Яндекс, ВКонтакте, GitHub). Доступность входа через провайдеров зависит от настроек сервера. В настройках профиля можно включать или отключать публичное отображение результатов; email и пароль в рейтинге не раскрываются.

Чтобы включить сообщения MAX, откройте **Настройки профиля → Сообщения от бота MAX → Подключить MAX**, перейдите по ссылке и нажмите «Начать». После подтверждения отдельно включаются ежедневные напоминания и итоги тренировок. На локальном сервере без настроенного бота соответствующие кнопки могут быть недоступны.

## Локальный запуск

Требуются **Python 3.10+**, **Node.js 20.19+**, npm и Git. Node.js с npm: https://nodejs.org/en/download/

```bash
git clone https://github.com/FS13Fid/CyberSprint_2026_Qualifying_Stage.git
cd CyberSprint_2026_Qualifying_Stage
npm ci
npm run build
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Откройте **http://127.0.0.1:8000**. По умолчанию SQLite создаётся в файле `typing_hero.db` рядом с `main.py`. **Локальная база не связана с базой публичного сайта:** участники на разных локальных копиях не встретятся в общей таблице и в гонках.

### Настройки сервера

| Переменная | Назначение |
| --- | --- |
| `CYBERSPRINT_DB_PATH` | Путь к существующей SQLite-базе |
| `CYBERSPRINT_DATA_SCOPE=server` | Метка общей серверной установки |
| `CYBERSPRINT_PUBLIC_URL` | Внешний HTTPS-адрес сайта |
| `CYBERSPRINT_TIMEZONE` | Часовой пояс практики (по умолчанию `Europe/Moscow`) |
| `MAX_BOT_TOKEN`, `MAX_BOT_USERNAME` | Подключение бота MAX |
| `MAX_WEBHOOK_SECRET` | Проверка запросов webhook от MAX |
| `MAX_CA_BUNDLE` | Дополнительный сертификат при необходимости |
| `GITHUB_OAUTH_CLIENT_ID`, `GITHUB_OAUTH_CLIENT_SECRET` | OAuth GitHub |
| `YANDEX_OAUTH_CLIENT_ID`, `YANDEX_OAUTH_CLIENT_SECRET` | OAuth Яндекса |
| `VK_ID_CLIENT_ID` | Авторизация VK ID |

Не размещайте токены, пароли, приватные SSH-ключи и SQLite-базу в GitHub.

## Обновление действующего сервера

**Сначала создайте резервную копию базы.** Сохраните действующие переменные окружения и текущую конфигурацию запуска. Обновите код из проверенной ветки, выполните `npm ci && npm run build`, установите зависимости Python и перезапустите существующий сервис (systemd, Docker или другой способ — в зависимости от вашей установки). Сохраните тот же `CYBERSPRINT_DB_PATH`. Миграции базы выполняются при запуске.

Не создавайте новую пустую базу вместо рабочей: это приведёт к исчезновению аккаунтов и истории с сайта. Старые результаты, для которых не сохранилась история клавиш, остаются в базе без выдуманного пересчёта.
